\section{Experiments}

\subsection{Setup}

\paragraph{Benchmark.} HM3D ObjectNav, Habitat simulator v0.2.1, val\_mini split (30 episodes).
6 object categories: bed, chair, sofa, toilet, tv\_monitor, plant.
Success threshold: 1.0m geodesic distance. Max 500 timesteps.

\paragraph{Infrastructure.} All multi-robot methods share:
Detectron2 + RedNet perception, 2D semantic map, FMM planner, frontier extraction every 25 steps, 2 cooperative robots.
Only frontier assignment differs.

\paragraph{Hardware.} 4x RTX 4090 (24GB each). Habitat sim on GPU 0+1, models on GPU 2+3.

\paragraph{Models.}
\begin{itemize}
    \item MindNav brain: MiniMax-M2.5 LLM via SiliconFlow API
    \item Co-NavGPT brain: MiniMax-M2.5 LLM via SiliconFlow API (same model)
    \item MCoCoNav VLM: Qwen2.5-VL-7B (local)
    \item EfficientNav VLM: Qwen2.5-VL-7B (adapted from LLaVA-34B original)
\end{itemize}

\subsection{Key Findings}

\begin{enumerate}
    \item VLM spatial reasoning collapses at 7B: Both VLM-based methods achieve 0\% SR despite using same exploration infrastructure that achieves 76\% with random assignment.
    \item KG > flat text: MindNav (73.3\% SR, 0.416 SPL) outperforms Co-NavGPT LLM (70.0\% SR, 0.306 SPL). SPL improvement (+36\% relative) is significant.
    \item Random is strong: Two robots with good infrastructure cover most rooms. Infrastructure matters more than brain.
    \item MindNav's advantage is efficiency (SPL): robots take shorter paths because KG provides room connectivity.
\end{enumerate}
